# SEC010 — Unpinned Action reference
- **Severity:** error (third-party) / warn (official `actions/*`)
- **Category:** security/supply-chain
- **What:** `uses: owner/repo@v4` (mutable tag/branch) instead of a full commit SHA.
- **Why:** Tags can be moved. Compromised tags have executed attacker code in CI (e.g., tj-actions/Trivy incident, Mar 2026).
- **Fix:** Pin to a full 40-char commit SHA and keep the version as a comment: `uses: actions/checkout@<sha> # v4.x.y`. Update via Dependabot/Renovate.
