# SEC005 — PR head checkout under `pull_request_target`
- **Severity:** error
- **Category:** security
- **What:** `actions/checkout` refs PR head while triggered by `pull_request_target`.
- **Why:** Runs untrusted code in a privileged context.
- **Fix:** Use `pull_request`, or do not check out/execute untrusted PR code in the privileged job.
