# SEC004 — `pull_request_target` risk
- **Severity:** warn
- **Category:** security
- **What:** Workflow uses `pull_request_target` (runs with base-repo permissions/secrets context).
- **Why:** Treat PR code/config as untrusted; combining with privileged steps can enable exfiltration or repo compromise.
- **Fix:** Prefer `pull_request` for untrusted code, isolate privileged work, and never execute untrusted PR code with write tokens.
