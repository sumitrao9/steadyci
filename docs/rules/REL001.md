# REL001 — Deprecated runner
- **Severity:** error
- **Category:** reliability
- **What:** Workflow targets a sunset runner image (e.g., `ubuntu-20.04`, `macos-11/12`).
- **Why:** Removed runners cause CI to fail without warning.
- **Fix:** Migrate to a supported runner (e.g., `ubuntu-24.04`) and validate the job.
