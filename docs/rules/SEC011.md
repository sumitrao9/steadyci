# SEC011 — Script injection via untrusted event data
- **Severity:** error
- **Category:** security
- **What:** `${{ github.event.* }}` / `github.head_ref` interpolated directly into a `run:` shell script.
- **Why:** PR titles/bodies/comments/refs can contain shell metacharacters and execute attacker-controlled commands.
- **Fix:** Pass untrusted values via `env:` and reference quoted shell variables: `env: TITLE: ${{ github.event.pull_request.title }}` then `run: echo "$TITLE"`.
